Как это работает

1

Регистрация

Почта, имя и пароль. У каждого участника свой профиль и бумажный счёт турнира.

2

Разметка

Смотрите структуру на графике площадки. Рядом — виджет TradingView для визуальной сверки.

3

Сделка

Вход, обязательный стоп и цель. Объём считается из процента риска, а не задаётся на глаз.

4

Зачёт

Ордера исполняются по нашему ряду свечей. Если стоп и цель задеты одной свечой — засчитывается стоп.

Честные правила

Отложенный ордер исполняется только свечами строго позже момента размещения — сыграть по уже известной цене нельзя. Если наш поток котировок отстаёт от рынка, торговля закрывается сразу для всех: иначе участник, глядящий в живой виджет, входил бы по устаревшей цене без риска. Спред вычитается из каждой сделки.
